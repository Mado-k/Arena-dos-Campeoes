# Ilustrações das cartas

SVGs exportados de `public/sprites.js` por `node gerar-pixelarts.js`, usando os
mesmos perfis das invocações. Os caminhos são persistidos em `cartas.imagem`.
A Grávida dos Robôs permanece adiada.

O arquivo `n022.svg` incorpora o quadro original do Dino do Chromium. A licença
BSD e a fonte estão em [LICENCA-CHROMIUM.txt](../efeitos/LICENCA-CHROMIUM.txt) e
[README dos efeitos](../efeitos/README.md).
